Mode d’emploi

  1. Ouvrez l’outil.

Questions fréquentes

Est-ce gratuit ?

Oui. Aucun compte ni abonnement n’est nécessaire.

Mes fichiers sont-ils envoyés ?

Non. Tout s’exécute dans votre navigateur et vos fichiers restent sur votre appareil.

Cela fonctionne-t-il sur mobile ?

Oui. Cela fonctionne dans les navigateurs récents, sur mobile comme sur ordinateur.

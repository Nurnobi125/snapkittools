গোপনীয়তা

আপনার ফাইল আপনার কাছেই থাকে।

সর্বশেষ হালনাগাদ: ২৫ অক্টোবর ২০২৬

SnapKit-এর এই স্ট্যাটিক সংস্করণে ছবি কনভার্ট, রিসাইজ এবং কালার বিশ্লেষণ আপনার ডিভাইসের ব্রাউজারে হয়। ছবি SnapKit-এর কোনো অ্যাপ সার্ভারে আপলোড করা হয় না। দৈনন্দিন text, developer, math/date ও unit tools-ও ব্রাউজারেই চলে; আপনার input SnapKit-এ পাঠানো হয় না।

ফাইল ও ডাউনলোড

আপনি যে ছবি নির্বাচন করেন সেটি ব্রাউজারের স্থানীয় মেমরিতে খোলে। ডাউনলোডের জন্য ব্রাউজার আপনার ডিভাইসে নতুন ফাইল তৈরি করে। পৃষ্ঠা বন্ধ করলে অস্থায়ী কাজের ডেটা মুছে যায়।

ওয়েবসাইট হোস্টিং

সাইটটি GitHub Pages-এ প্রকাশ করলে GitHub আপনার ব্রাউজার অনুরোধ ও নিরাপত্তা-সংক্রান্ত লগ পরিচালনা করতে পারে। GitHub-এর নিজস্ব গোপনীয়তা নীতি ও শর্ত প্রযোজ্য। PDF edit-এর জন্য pdf-lib এবং PDF page-কে PNG/JPG করতে PDF.js jsDelivr CDN থেকে ব্রাউজারে লোড হয়; নির্বাচিত PDF ফাইল CDN-এ পাঠানো হয় না। CDN-এ লাইব্রেরি লোডের সাধারণ অনুরোধ তথ্য দৃশ্যমান হতে পারে। এই সংস্করণে SnapKit-এর নিজস্ব analytics, বিজ্ঞাপন, কুকি, অ্যাকাউন্ট বা যোগাযোগ ফর্ম নেই।

Chrome extension

SnapKit Tools Chrome extension-এ আপনার পছন্দের tool favorites, সর্বশেষ খোলা সর্বোচ্চ আটটি tool এবং light/dark theme পছন্দ extension-এর browser local storage-এ থাকে। এই তথ্য আপনার ডিভাইসেই থাকে; SnapKit-এ পাঠানো বা তৃতীয় পক্ষের সঙ্গে ভাগ করা হয় না। Extension সরালে বা এর local data মুছলে তথ্যও মুছে যায়। Extension আপনার browsing history বা খোলা webpage-এর বিষয়বস্তু পড়ে না।

সীমাবদ্ধতা

ব্রাউজারের ফরম্যাট-সমর্থন ও ডিভাইসের মেমরির ওপর কিছু ছবি খোলা বা রূপান্তর নির্ভর করে। EXIF ক্লিনার ছবির নতুন PNG কপি তৈরি করে, কিন্তু সব ধরনের metadata অপসারণের নিশ্চয়তা দেয় না। সংবেদনশীল ফাইল ব্যবহারের আগে ফল যাচাই করুন।

নীতি পরিবর্তন

ভবিষ্যতে analytics, বিজ্ঞাপন, অ্যাকাউন্ট বা সার্ভার-ভিত্তিক ফিচার যোগ করলে এই পাতাটি আপডেট করতে হবে, এবং কী তথ্য কেন সংগ্রহ হয় তা স্পষ্টভাবে জানাতে হবে।
